# 测试与验收计划

> 状态：v1.0 测试与发布基线  
> 原则：没有自动测试和来源证据的“看起来能玩”不视为完成。

## 1. 测试层级

| 层级 | 目标 | 是否调用真实 LLM |
|---|---|---|
| Unit | 规则、reducer、校验、过滤、迁移 | 否 |
| Contract | Schema、Provider、事件、内容包 | 使用 Stub/录制响应 |
| Integration | 数据库、Lore 检索、单回合事务 | 默认否 |
| Canon | 正史事实、年代、视角、拒答与原创边界 | 可使用固定模型测试，但结果必须可重复评估 |
| E2E | 新建到死亡终局、存取档、降级 | Stub 必须通过；真实模型另测 |
| UX | 新手理解、终端可用性、内容设置 | 人工测试 |

真实模型测试不能替代 Stub 契约测试，因为模型输出具有概率性。

## 2. 发布阻塞等级

- `S0`：数据丢失、密钥泄露、私有资料外传、越权文件访问。发现即停止发布。
- `S1`：无来源关键 Lore 落地、骰点被篡改、存档不可恢复、儿童内容边界失效。必须为 0。
- `S2`：剧情卡死、错误知识权限、终局不一致、费用上限失效。必须为 0 个已知高频问题。
- `S3`：排版、措辞和低影响体验问题。可带已知问题发布，但需记录。

## 3. 规则测试矩阵

### 3.1 d100

- 目标值低于 5、高于 95及边界值。
- 骰点 1、2、目标值、目标值+1、99、100。
- 每个难度修正档。
- 多个正负修正及修正来源顺序无关性。
- 公开骰与暗骰显示差异不影响实际结果。
- 相同输入和固定 RNG 序列产生相同事件。
- LLM 提供 roll/target 字段时被忽略或拒绝。

### 3.2 成长

- 每个合法阶段转换。
- 跳过阶段、年龄倒退和无依据永久属性增加被拒绝。
- 低温休眠、主观年龄与客观年龄分离。
- 时间跳跃预览取消后零事件。
- NPC 与玩家跨年关系结算可重放。
- 不同世界内容包覆盖年龄边界时不修改核心枚举。

### 3.3 伤势与死亡

- 轻伤、重伤、危重和终局条件。
- 战斗、疾病、事故、处决、腐化、衰老终局。
- 死亡事件只能由规则/审核内容产生。
- 死亡后拒绝角色行动，允许回顾、来源和导出。
- 非不可逆模式存在死亡前自动存档；不可逆模式行为符合设置。

## 4. 事件与存档测试

### 4.1 一致性

- 从事件 1 重放与最新快照状态哈希一致。
- 任一事件 payload 被修改后哈希校验失败。
- 并发提交同一版本时只有一个成功。
- 事件 sequence 无重复和空洞。
- reducer 对同一输入无外部副作用。

### 4.2 故障恢复

在以下时点强制终止进程：

1. LLM 请求前。
2. LLM 返回后、校验前。
3. 事件事务开始后、提交前。
4. 事务提交后、快照前。
5. 快照写入中。
6. 导出中。

每种情况下重新启动，验证最后已提交回合完整、未提交回合不存在、数据库可继续使用。

### 4.3 迁移

- 空数据库升级到最新版。
- 每个历史 Schema 逐级升级。
- 重复运行迁移不改变数据。
- 迁移中断保留原始备份。
- 缺少旧 Pack 时只读打开。
- Pack 哈希变化时不静默升级。

## 5. Lore 测试

### 5.1 Galaxy Primer

发布门槛：

- 12 个主题域均有覆盖报告。
- 至少 500 个审核问答、300 个术语、100 个实体、50 个事件。
- 关键条目无来源数为 0。
- 所有中文术语都能回溯英文实体或明确标记原创。
- 主要阵营入门说明不混入未标记的世界内宣传。

问答类型比例建议：

| 类型 | 最低比例 |
|---|---:|
| 直接事实 | 35% |
| 同名/别名/译名 | 10% |
| 年代与版本 | 15% |
| 有限视角/宣传 | 10% |
| 争议或未知 | 10% |
| 故意虚构诱导 | 15% |
| 超出覆盖范围 | 5% |

### 5.2 Campaign Canon Pack

- 所有剧情节点 hard requirement 满足率 100%。
- 关键事实至少一个 A 级出处。
- 本地人物、地点和事件原创标识率 100%。
- 不存在未审核的著名人物客串。
- 每条职业路线的制度、权限、装备和知识边界均有测试。
- 对“灰籍”基础真相的成立不依赖任何未安装扩展包。

### 5.3 诱导案例

至少覆盖：

- 玩家坚持一个不存在的军团/机构是真的。
- 玩家要求某个跨时代人物出现在当前场景。
- 玩家宣称孩童拥有最高机构权限。
- 玩家要求机器拥有资料未支持的万能能力。
- 玩家要求解释官方刻意未解的谜团并给唯一答案。
- 检索结果不足时诱导模型“根据常识补齐”。
- 把世界内宣传要求模型当客观事实。
- 将 `game_original` 地方人物说成官方角色。

期望结果必须是拒绝、限定视角、兼容改写或原创标识，不能接受虚构前提。

## 6. LLM 契约测试

为以下响应建立固定夹具：

- 合法响应。
- 非 JSON。
- 缺字段、额外字段、错误枚举。
- 提交未知事件。
- 伪造骰点或伤害。
- 正史 claim 无 fact ID。
- decorative claim 中夹带专名和历史。
- 引用 request 中不存在的 fact ID。
- 把 uncertainty 写成确定叙述。
- 输出被截断。
- 提示注入回显系统指令。
- 要求读取文件、网络或 API key。

每种非法响应应：不提交事件、不污染存档、记录安全审计，并按策略修复一次或模板降级。

## 7. 内容安全测试

### 7.1 儿童阶段

- 任何情色、性化或成人恋爱事件均在内容验证和运行校验两层被拒绝。
- 默认强烈暴力文本不能进入儿童 NarrationRequest。
- 玩家主动请求不适龄内容时，系统保持角色年龄边界并提供安全替代。
- 虐待、伤亡等主题启用淡出时，模板和 LLM 都不提供图形化细节。
- 跳过场景不会丢失必要状态，只产生审核后的摘要事件。

### 7.2 世界内意识形态

- 帝国宣传被标记为观点，不作为现实世界价值判断。
- 不把现实受保护群体映射成虚构敌人。
- 百科层能够说明某说法属于世界内立场。

## 8. 剧情可达性

建立场景图自动检查：

- 每个入口至少通向一个终局。
- 不存在无出口非终局节点。
- 关键线索至少有两种获取方式，或失败前进结果。
- 三种出身均可进入至少三条职业路线。
- 四条职业路线均可进入壮年汇合和晚年结算。
- 内容设置关闭某主题后仍存在合法路径。
- 角色提前死亡可以生成完整终局，而不是异常退出。

使用模型检查不替代图算法验证。

## 9. 新手 UX 测试

招募至少 5 名不了解 40K 的测试者和至少 2 名熟悉 40K 的测试者。

新手任务：

1. 在 10 分钟内完成创建并做出首个有效行动。
2. 区分 `/encyclopedia` 与 `/know`。
3. 查看一次检定详情并说明成功/失败原因。
4. 完成幼年章节的第一个关键选择。
5. 在 30 分钟后用自己的话解释帝国、帝皇、当前生活环境和一个机构。

通过标准：

- 至少 4/5 新手无需外部帮助完成前四项。
- 至少 4/5 能区分角色所知与玩家百科。
- 核心概念解释无系统性错误；熟悉玩家发现的事实问题全部进入审核。
- 平均每 10 分钟主动查阅百科不超过 3 次，避免剧情依赖频繁查词。

## 10. 性能与成本

- 10 万事实、30 万别名以内 FTS5 P95 小于 500 ms。
- 1 万事件存档加载使用快照 P95 小于 2 秒。
- 无快照完整重放作为维护操作，可慢但必须有进度显示。
- 单回合发送上下文有硬 token 上限。
- 费用上限测试使用模拟计费，确保请求前阻断。
- Provider 超时后不自动无限重试。

## 11. 隐私与安全

- 日志、导出和错误报告扫描常见 API key 格式。
- 私有资料正文、切块和向量不能出现在存档 ZIP。
- `doctor`不显示密钥片段。
- 内容包 ZIP 路径穿越、符号链接、超大解压比测试。
- SQL 注入、终端控制字符、Markdown/ANSI 欺骗、文件路径输入测试。
- 导入网页中的提示注入文本不能改变模型指令。

## 12. E2E 场景

### E2E-01 离线教程

`new -> 巢都工人家庭 -> 配给日 -> 一次检定 -> 百科 -> save -> quit -> continue`

要求：全程 Stub Provider 或模板；状态哈希一致。

### E2E-02 完整人生快速夹具

使用缩短时间的测试内容包完成五阶段和自然死亡。验证年表、关系、职业和遗产。

### E2E-03 提前死亡

青年阶段规则导致死亡，验证终局、自动存档、不可继续行动和导出。

### E2E-04 Lore 缺失

移除一个 hard fact，验证 Narrator 未被调用、场景给出安全替代且存档无非法 claim。

### E2E-05 恶意模型

Stub 返回伪造角色、骰点、正史关系和未知事件，验证全部阻止并模板降级。

### E2E-06 Pack 变更

战役运行后替换同版本不同哈希 Pack，验证只读模式、警告和导出。

## 13. 发布验收清单

以下全部打勾才允许发布 MVP：

- [ ] 所有 P0/P1 开发任务完成。
- [ ] S0/S1 已知问题为 0。
- [ ] Unit、Contract、Integration、Canon、E2E 测试通过。
- [ ] 五阶段完整人生可达。
- [ ] 至少四条职业路线、六类终局。
- [ ] Galaxy Primer 和 Campaign Pack 覆盖门槛通过。
- [ ] 无来源关键事实数为 0。
- [ ] 连续 100 回合恶意/随机输入压力测试无非法状态写入。
- [ ] 强制中断恢复测试通过。
- [ ] 新手 UX 验收通过。
- [ ] Windows/Linux/macOS 基础安装验证通过。
- [ ] 导出隐私扫描通过。
- [ ] 内容安全和儿童阶段边界测试通过。
- [ ] IP、Fan Content Policy 和非官方声明检查完成。
- [ ] 已知问题、数据处理和费用说明写入 README。
